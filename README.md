# 📊 Análise de Desempenho Educacional

Projeto de análise de dados educacionais desenvolvido para identificar padrões de desempenho, frequência e aprovação de alunos.

## 🎯 Objetivo

Transformar dados educacionais em indicadores que possam apoiar a análise do desempenho acadêmico.

## 📌 Indicadores

- Total de alunos
- Média geral das notas
- Frequência média
- Taxa de aprovação
- Média por disciplina
- Média por turma

## 🛠️ Tecnologias

- Python
- Pandas
- SQL
- Power BI

## 📁 Estrutura

- `dados/` — base de dados
- `python/` — análise com Python/Pandas
- `sql/` — consultas SQL
- `docs/` — documentação da análise
- `dashboard/` — dashboard desenvolvido no Power BI

## 📊 Dashboard

O dashboard apresenta os principais indicadores de desempenho educacional e permite analisar os dados por turma e disciplina.

## ⚠️ Dados

Os dados são fictícios e foram criados exclusivamente para fins de estudo e demonstração de habilidades em análise de dados.

# Análise de Desempenho Educacional

## Objetivo

Analisar dados acadêmicos para identificar padrões de desempenho, frequência e aprovação dos alunos.

## Indicadores analisados

- Total de alunos
- Média geral das notas
- Frequência média
- Taxa de aprovação
- Desempenho por disciplina
- Desempenho por turma

## Perguntas de negócio

- Qual é a média geral dos alunos?
- Qual é a taxa de aprovação?
- Qual disciplina apresenta maior média?
- Qual turma apresenta melhor desempenho?
- Existe relação entre frequência e desempenho?

## Tecnologias

- Python
- Pandas
- SQL
- Power BI

## Observação

Os dados utilizados neste projeto são fictícios e foram criados exclusivamente para fins de estudo e demonstração de habilidades em análise de dados.
